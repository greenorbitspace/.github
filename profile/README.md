## Contributing

If you’re contributing to one of our repositories:

1. Read the repository README first.
2. Check the issue tracker and current branch strategy.
3. Keep changes small and well described.
4. Document anything that changes behavior, setup, or public output.
5. Prefer clear code, simple abstractions, and explicit naming.
